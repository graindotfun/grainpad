# Agent routing for the public source release

This repository is an intentionally read-only, reviewed public source distribution of the launchpad and GRN1 verification tools. Ordinary product development, commits, pushes, pull requests, operational notes and progress logs belong in the authorized private application workspace. If that workspace is unavailable, stop writing and request access; never use this public checkout as a fallback.

A session name or an old repository URL is not write authorization. Before any write, verify the actual repository identity, visibility and push destination. Public releases require the owner-authorized publication path and a concrete sanitized source review. Do not mirror private Git history, add private branches or tags, or publish a private-to-public commit map.

Never commit credentials, wallet exports, user records, production settings, internal budgets, conversations, incident reports or operational logs. Preserve transaction validation, signature domains, source-frozen rights and the existing market hold. Source publication does not authorize signing, transactions or deployment.

The public manifest is a positive inventory of reviewed regular files. Run npm test, npm run verify:public, npm run build, and secret scans of both the tree and reachable history before an owner-authorized public release. Keep generated build output and source maps out of Git. Do not add deployment workflows.
