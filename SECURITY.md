# Security reporting

Send vulnerability reports privately to
[security@grainpad.fun](mailto:security@grainpad.fun). Include the affected
public commit, expected and observed behavior, impact and a minimal reproduction
using disposable test data. Contact delivery has no promised response SLA.

Do not put seeds, wallet exports, authenticated endpoints, user records or
exploit instructions for a live service in a public issue. Do not move real
funds to demonstrate a defect. For a nonsensitive contact request, use
[@GrainXMR](https://x.com/GrainXMR).

The published tools are not independently audited. Read the verification
boundaries before interpreting an observation as proof.
